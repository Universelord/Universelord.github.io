So for like the past month or so I have been radio Silent right? It is becaues I have been having some irl things I need to cross 😥,

and also I have been making a project called Indigo Os.

What is it?#

well it is a Universal Blue based immutable linux distor for like computer labs in schools, it focuses on languages like python and sql (mostly because thats what is in my school ncert and cbse syllabus).

I also added things like Vscodium and also some restrictions for installing extensions using the policy.json in /etc/vscodium/policy.json

But Why?#

when compared to stuff like Microsoft Windows or even regular Linux, the Indigo Os approach is way better since

  • the systems will break less,
  • auto update with no update screen,
  • A windows like ui (Mainly due to Kde Plasma),
  • Rollback support,
  • built in python and vscode support
