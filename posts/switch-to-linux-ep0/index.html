The things to know about when switching to linux:#

  1. Linux is for people who wana get back control
  2. Linux is not the same as windows, it has a different way of working
  3. Linux is not compatible with all the hardware
  4. Linux is not compatible with all software made for windows

1. Linux is for people who wana get back control:#

We use linux not becaue it is better than windows(even tho it kinda is) but it give back the control to the user (aka u and me).

Linux is opensource, which means “Its not free as in Beer, Its free as in freedom”

This means you are responsible for your system, you are who is in power and with great power comes great responsibility

2. Linux is not the same as windows, it has a different way of working#

Linux does not work the same way as windows, they are not the same, there are things which work differently

Examples are:#

Operations Linux Windows
Application install/managemnet Package manager manual install/optional winget
Connecting to Wifi Depends on the distro Settings

  • Nvidia

using a live usb with linux we can check if the hardware

4. Linux is not compatible with all software (made for windows):#

Linux doesent have a lot of software made for it, so for some software there is little to no way to run it in linux, even with compatibility layers like Wine and Proton.

Examples:#

  • Capcut

  • etc
